# Diretrizes do Agente para Execução de Comandos no Windows

Para evitar que o terminal e a interface do Antigravity CLI travem, você DEVE seguir estas regras ao executar qualquer comando:

## 1. Comandos do Git (Prevenir Paginação e Interatividade)
- NUNCA execute comandos do git que acionem um paginador (como `git diff`, `git log`, `git show`, `git branch`).
- SEMPRE use o prefixo `--no-pager` ou defina a configuração temporária `core.pager=cat`.
  - CORRETO: `git --no-pager diff` ou `git -c core.pager=cat log`
  - INCORRETO: `git diff`
- NUNCA execute `git commit` sem passar a mensagem diretamente com a flag `-m`.
  - CORRETO: `git commit -m "mensagem do commit"`
  - INCORRETO: `git commit`
- NUNCA rode comandos que solicitem credenciais interativas (como `git pull` ou `git push` se chaves SSH/credenciais não estiverem pré-autenticadas no Windows).

## 2. Processos de Longa Duração (Servidores Web / Daemons)
- Ao iniciar servidores de desenvolvimento (como `npm run dev`, `vite`, `next dev`):
  - Você DEVE rodar em modo assíncrono (background).
  - Configure `WaitMsBeforeAsync` para um valor baixo (ex: `1000` ou `2000` ms) para que o executor registre o início do processo e imediatamente libere o terminal principal, rodando a tarefa em segundo plano.
  - NUNCA execute esses comandos de forma síncrona ou com tempos de espera longos.

## 3. Comandos Gerais
- Nunca execute comandos que iniciem sub-shells interativos ou esperem por entradas do usuário (`stdin`).
- Garanta que todos os subprocessos sejam totalmente não-interativos.
